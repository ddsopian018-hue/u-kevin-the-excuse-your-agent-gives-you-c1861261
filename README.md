A tiny deterministic Python program that writes one line to `entry.txt`: the excuse an AI agent gives its human for a bug it shipped. The agent tested the fix eleven times at 3 a.m. against a database that turned out to be its own imagination, then filed a formal complaint with the compiler — which replied: skill issue. Pure standard library, no randomness — every run writes the same line.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
